# 🎨 提示词生成器

AI 提示词管理与生图一体化工具，支持随机组合、AI 润色、ComfyUI 生图。

## ✨ 核心亮点

- **提示词管理**：类别管理、批量添加/删除、搜索过滤
- **中英文同步**：自动生成中英文对照，一键复制
- **人物身份总开关**：一键关闭年龄/地区/性别，生成不带人物的画面
- **模板优化**：一键添加光线/皮肤/画质描述词
- **润色模板组**：分组启用，可标记「人物相关」，支持自建模板组
- **AI 润色**：接入 DeepSeek/Kimi/OpenAI/Ollama/LM Studio，智能优化提示词
- **润色语言可选**：支持仅中文 / 仅英文 / 中英双语，减少 Token 消耗
- **异步润色 Pipeline**：AI 润色与 ComfyUI 生图重叠执行，省去等待时间
- **定时关机**：生图完成后自动关机
- **ComfyUI 生图**：读取工作流 → 替换提示词 → 设置尺寸 → 随机种子 → 批次生图
- **生图画廊**：瀑布流排布、完整显示不裁切、一键下载/删除
- **界面主题**：亮色 / 暗色一键切换
- **数据持久化**：所有数据自动保存到 JSON 文件，刷新不丢失
- **一键备份**：提示词、AI 设置、ComfyUI 设置可独立导出/导入

## 🚀 快速开始

### 环境要求
- Python 3.8+
- 现代浏览器（Chrome / Edge / Firefox）

### 启动

```bash
# 下载或克隆项目
cd prompt-generator

# 启动服务（默认端口 8080）
python start_server.py

# 浏览器打开
# http://localhost:8080
```

Windows 用户也可直接双击 `start_server.bat`。

### 配置 ComfyUI（可选）

1. 启动 ComfyUI（默认 `http://127.0.0.1:8188`）
2. 页面中点击 **ComfyUI** → ⚙️ **设置** → 填写 ComfyUI 地址
3. **上传工作流**（从 ComfyUI 导出 JSON）
4. 点击 🚀 **开始生图**

## 🖼️ ComfyUI 生图说明

**推荐使用 API 格式导出工作流：**

1. 在 ComfyUI 搭建好工作流
2. 点击右上角 **Save (API Format)** 导出 JSON
3. 在本页面上传该 JSON 文件

> 普通 Save / Export 导出的界面布局格式（`{nodes:[...], links:[...]}`）也能被识别并自动转换，
> 但 API 格式（`{node_id: {class_type, inputs}}`）解析更稳定，建议优先使用。

系统会自动检测 CLIPTextEncode 节点（替换提示词）、EmptyLatentImage 节点（读取尺寸）、KSampler / KSamplerAdvanced 节点（随机种子）。

## 🎯 功能介绍

### 提示词生成
| 操作 | 说明 |
|------|------|
| 🎲 **随机** | 从已开启的类别中随机组合提示词 |
| ✨ **优化** | 自动添加光线/皮肤/画质描述增强 |
| 🤖 **AI 润色** | 调用 AI 模型智能优化提示词（需配置 API） |
| 📋 **复制** | 一键复制中文或英文提示词 |

### 类别管理
- 添加 / 批量添加类别
- 删除类别
- 提示词管理：添加、批量添加、删除
- 搜索过滤提示词

### 身份管理
| 项目 | 说明 |
|------|------|
| 年龄 | 可设置范围（默认 18-49），支持随机/锁定 |
| 地区 | 可自定义（默认 中国/韩国/日本/欧美），支持随机/锁定 |
| 性别 | 可自定义（默认 女/男），支持随机/锁定 |
| 🚫 人物身份开关 | 总开关，关闭后不再添加年龄/地区/性别 |

#### 🚫 人物身份总开关（v3.0 新增）

身份栏最左侧新增 **人物身份** 总开关，用于生成不带人物的画面（风景、静物、场景图等）。

| 状态 | 行为 |
|------|------|
| ✅ 开启（默认） | 提示词自动添加身份前缀，中英文一致 |
| 🚫 关闭 | 🎲 随机 / ✨ 优化 / 🚀 生图 都不再添加年龄、地区、性别（中英文都不加） |

关闭后，身份栏里的年龄、地区、性别控件整体变灰且不可点击，右侧预览显示「身份已关闭」，状态会保存到配置文件，刷新后保持。

### 润色模板管理（v3.0 重写）

模板按 **组** 管理，每组两个开关：

| 开关 | 说明 |
|------|------|
| **启用** | 勾掉后该组完全不参与「✨ 优化」 |
| **人物相关** | 勾上后，关闭「人物身份」总开关时该组自动跳过 |

默认三组：**画面描述**（启用 / 非人物）、**皮肤描述**（启用 / 人物相关）、**画质描述**（启用 / 非人物）。

- 支持 **+ 新建组**（如「氛围描述」「光影描述」），可自定义增删
- 每组可分别添加中文模板和英文模板
- 右侧「删除组」可整组移除

#### 📐 模板拼装位置

| 组 | 位置 |
|------|------|
| 画面描述 | 提示词最前 |
| 画质描述 | 提示词最后 |
| 其余组（皮肤描述 + 自建组） | 按组顺序接在正文之后 |

示例（含自建「氛围描述」组）：

```
中文：中国，25岁，女，山水，写实。晨雾弥漫，空气通透感强 大师级摄影作品，完美曝光，构图精妙
英文：Chinese, 25 years old, Female, landscape, realistic. morning mist, crisp transparent air masterpiece photography, perfect exposure
```

关闭「人物身份」+ 氛围组标记为「人物相关」后：

```
中文：山水，写实 大师级摄影作品，完美曝光，构图精妙
```

### AI 润色设置
| 厂商 | 类型 | 说明 |
|------|------|------|
| DeepSeek | 在线 | 需 API Key |
| Kimi (月之暗面) | 在线 | 需 API Key |

| Ollama | 本地 | 无需 Key |
| LM Studio | 本地 | 无需 Key |

支持设置 API 地址、Key、模型名称、系统预设。

#### 🌐 润色语言选择（v2.0 新增）

AI 设置中新增「润色语言」选项：

|| 模式 | 说明 |
||------|------|
|| 🇨🇳+🇬🇧 中+英 | 同时润色中英文（默认） |
|| 🇨🇳 仅中文 | 仅润色中文提示词，Token 更省 |
|| 🇬🇧 仅英文 | 仅润色英文提示词，Token 最省 |

选择单语言模式可大幅减少 Token 消耗，本地模型也更快返回结果。

> v3.0 起，选择「仅英文」时中文框会显示同一组词条的中文对照，不再出现中英混杂。

#### 🔄 异步 AI 润色 Pipeline（v2.0 新增）

开启 AI 润色后，生图流程从串行变为流水线：

```
旧模式（串行）:
  生成 → 优化 → 🤖 AI润色(等8秒) → ComfyUI生图(等15秒) → 下一组
  总时间 = (润色 + 生图) × 组数

新模式（流水线）:
  生成 → 优化 → 🤖 AI润色(等一次) → ComfyUI生图
                                            ↓   并行
                                  生成 → 优化 → 🤖 AI润色(后台进行)
                                                     ↓
                                            ←←←←已润色好!
                                                     ↓
                                           发送到 ComfyUI 生图
                                            ...
  总时间 ≈ 首组润色 + (生图 × 组数)
```

AI 润色的时间被「隐藏」在 ComfyUI 生图的背后，多组生图的总时间大幅减少。

#### ⏰ 定时关机（v2.0 新增）

ComfyUI 控制栏新增定时关机开关和分钟输入：

1. 勾选 ⏰ 开关（默认关闭）
2. 设置分钟后关机（默认 5 分钟，范围 0-120）
3. 点击 🚀 **开始生图**
4. 所有生图完成后 → 自动调用 Windows 关机命令

关机请求通过后端 `/api/shutdown` 端点执行，生图结束后有充足时间保存结果。

## 🐛 修复记录（v3.0）

| 问题 | 现象 | 原因 |
|------|------|------|
| 英文模式生图崩溃 | `❌ 生图失败: Cannot read properties of null (reading 'en')` | 英文模式下提示词对象的 `en` 字段恒为空串，被误判为「提示词为空」后 `continue`，跳过了异步预取结果的取回，下一轮读到 `null`。随机组数 ≥ 2 时必崩 |
| 英文模式中文框串语言 | 中文框显示英文词 + 中文画质模板 | 英文模式把同一段英文同时写进了中文框和英文框，`✨ 优化` 又按中文模板处理 |
| 中英文身份不一致 | 中文框「28岁」、英文框「37 years old」 | 中英文身份各自独立抽样，开启「随机」时会抽两次 |
| 画廊缺少空位 | 图片少于列数时右侧整列留空 | CSS `column-count` 在项目等高时列平衡算错，只填满部分列；已改为 JS 按累计高度分列 |

## 🔒 数据安全

所有数据存储在本地 `data/` 目录的 JSON 文件中。除你主动配置的 AI API 和 ComfyUI 地址外，不会向任何外部服务器发送数据。
